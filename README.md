# Haj4ever

Build a blåhaj project. Get a real blåhaj.

Haj4ever is a Hack Club YSWS (You Ship, We Ship) program run by Team Haj4ever in partnership with Hack Club. This repo is the landing page.

## How it works

1. **Make a blåhaj project.** Any project with a blåhaj theme counts, an app, game, tool, visualizer, physical build, whatever. It just needs to be something you actually built with real time behind it.
2. **Log around 7-8 hours.** That's the bar. You can split it across multiple projects, they all add up. Each qualifying batch of hours gets you one blåhaj.
3. **Submit and check your mailbox.** Send your project link and hours log to [haj4ever.fillout.com/submit](https://haj4ever.fillout.com/submit). We review it, and if it checks out, a blåhaj is on its way to you.

If we can't ship to your region, you'll get a $30 grant to buy one yourself instead.

## Stack

Single static HTML page. No build step, no framework. Styled with vanilla CSS using [Instrument Sans](https://fonts.google.com/specimen/Instrument+Sans). Images are embedded as base64 so the page works fully offline.

## Running locally

Just open `index.html` in a browser. That's it.
